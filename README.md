# Estandarte Dental Clinic System

A full-stack **Appointment and Billing Management System** for Estandarte Dental Clinic built with **React + Firebase**.

This system manages patients, doctors, staff workflows, appointments, billing, and clinic operations in a secure role-based environment.

---

## 🚀 Features

- 🔐 Authentication system (Admin, Doctor, Staff, Patient)
- 📅 Appointment booking and management
- 🦷 Doctor dashboard for patient schedules
- 🧾 Billing and invoice generation
- 📊 Admin control panel for clinic management
- 🔔 Notifications system
- 🔥 Firebase Firestore backend with security rules

---

## 🧱 Tech Stack

- **Frontend:** React (TypeScript)
- **Backend:** Firebase (Firestore, Auth)
- **Styling:** CSS / Custom UI components
- **Deployment:** Firebase Hosting (optional)
