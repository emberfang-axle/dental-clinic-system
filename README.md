🦷 Dental Clinic Appointment and Billing System

A modern, full-stack dental clinic management system with appointment scheduling, patient records, billing, and payment integration.

About the Project

This Dental Clinic Appointment and Billing System is a comprehensive web application designed to streamline dental clinic operations. It provides separate interfaces for doctors, staff, and patients to manage appointments, patient records, billing, and payments efficiently.

Features

👨‍⚕️ Doctor Features View and manage appointments Set service prices and exact bill amounts Add feedback notes for patients Manage personal schedule View patient medical history Searchable doctor profile for patients

👩‍💼 Staff Features Book and manage appointments Process payments (GCash integration) Cancel appointments (on doctor's orders) Manage patient records Generate bills and invoices

🙋 Patient Features Register and login Book appointments Cancel own appointments Search and view doctor profiles Make payments via GCash Give feedback and ratings View appointment history

🛠️ System Features Role-based access control (RBAC) Real-time data updates Google Calendar integration Modern responsive UI Secure authentication Data persistence with Firebase
